# Historical Review Reports

The files in this directory are point-in-time implementation review evidence from
the pre-migration project workflow. Preserve them as historical records.

Current review/verification/evaluation evidence for an active Work Block belongs
under `docs/reports/` and must be bound to the reviewed revision.

A historical `APPROVED`, `PASSED`, or next-stage recommendation does not grant
current source-write, merge, deployment, live-database, credential, or live
trading authority. Re-verify the referenced code/tests against the current
revision before relying on the verdict; if that binding cannot be established,
current applicability is `UNKNOWN`.
