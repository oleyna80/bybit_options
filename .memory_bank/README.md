# Memory Bank

This folder stores durable, session-to-session project context.

- Do not store secrets (API keys, tokens, credentials).
- Keep content short, factual, and link to source files where possible.

Core files:
- `projectbrief.md`
- `productContext.md`
- `activeContext.md`
- `systemPatterns.md`
- `techContext.md`
- `progress.md`
