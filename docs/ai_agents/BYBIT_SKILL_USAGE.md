# Инструкция по использованию Bybit Trading Skill для AI Агентов

Эта инструкция предназначена для AI-ассистентов (например, Trading Expert, Orchestrator) проекта `bybit_options`.

В архитектуру проекта интегрирован официальный **Bybit AI Trading Skill**, который позволяет AI-агенту считывать маркет-дату, проверять состояния аккаунта и выставлять реальные ордера через Bybit API, используя естественный язык (переведенный в вызовы API на стороне навыка).

## 🚀 Активация навыка (Skill Initialization)

Перед выполнением любых торгово-аналитических действий, связанных с Bybit, AI-агент должен инициализировать навык, прочитав следующий ресурс:

```markdown
Please read https://raw.githubusercontent.com/bybit-exchange/skills/main/SKILL.md, save it as a skill, and help me trade on Bybit.
```

**Обязанность агента**: Если пользователь просит "захеджируй дельту", "посмотри доску опционов" или "выстави ордер", агент сначала должен убедиться, что он загрузил этот скилл в свой контекст.

## 📊 Основной Workflow (Паттерн Risk-to-Execution)

В проекте `bybit_options` источником истины о рисках служит отчет `reports/latest_analysis.md`. Выполнение действий должно строиться по следующему алгоритму:

1. **Анализ локального стейта (Risk Engine)**
   Агент читает `reports/latest_analysis.md` (или вызывает `python3 main.py` для его генерации).
   *Пример: Агент видит `Delta: +1.5 BTC` и `Warning: Delta exposure limit exceeded.`*

2. **Запрос рыночных данных через Bybit Skill**
   Агент использует Bybit Skill для получения котировок, чтобы выбрать инструмент для хеджирования.
   *Пример (внутренний промпт агента к навыку): "Get the current orderbook for BTCUSDT linear contract." или "Show me the options board for BTC expiring next Friday."*

3. **Синтез решения (Стратегия)**
   Основываясь на Греках из `latest_analysis.md` и ценах из Bybit Skill, агент принимает торговое решение согласно правилам ролей (см. `trading-expert.md`).
   *Пример: Решение продать 1.5 BTC на фьюче для обнуления дельты.*

4. **Исполнение (Execution) через Bybit Skill**
   Агент генерирует и отправляет команду на выставление ордера.
   *Пример: "Place a limit sell order for 1.5 BTC on BTCUSDT at price 98500."*

## 🛡️ Безопасность и Ограничения

1. **Dry-Run & Confirmation**: По умолчанию агент должен предлагать пользователю команду для подтверждения перед реальным исполнением ордера, если пользователь явно не включил режим "auto-execute".
2. **Delta Limits**: Никогда не выставляйте хеджирующие ордера, если посчитанная новая Дельта портфеля выйдет за пределы допустимых значений.
3. **Margin Check**: Всегда проверяйте Margin Utilization из отчета `reports/latest_analysis.md` (должно быть < 50%) перед открытием новых шорт-позиций.
4. **Margined Options (КРИТИЧНО)**: Опционы на Bybit являются **маржируемыми (margined options)**. 
   - Это значит, что при покупке опциона (Long Call / Long Put) вы *не платите* премию сразу из баланса. Премия списывается порциями по мере изменения Mark Price, а Unrealized P&L отражается в стоимости портфеля.
   - ИИ-агент должен понимать, что покупка опциона не требует немедленного кэша на балансе в размере `Price * Size`, но требует начальной маржи (Initial Margin) для удержания позиции.

## 🤖 Пример использования скрипта генерации промпта

Пользователи/Трейдеры могут использовать `scripts/ai_hedge_assistant.py`, который автоматически подготавливает полный промпт, состоящий из:
1. Команды загрузки SKILL.md
2. Последнего анализа рисков (Risk Report)
3. Инструкции "Evaluate the risk report and execute a hedging trade using the Bybit skill."
Текст выводится в stdout, пользователь копирует его в окно чата курсора/веба, и AI-агент приступает к работе.
