## 🔧 Исправленные проблемы

### 1. **API баг с дублированием префиксов**
- **Проблема:** Frontend отправлял запросы на `/api/v1/api/v1/endpoint` вместо `/api/v1/endpoint`
- **Решение:** Проверена и исправлена логика префиксов в `api.ts`
- **Статус:** ✅ Исправлено

### 2. **Отсутствующие backend endpoints**
- **Проблема:** Frontend пытался вызывать endpoints, которые не существуют в бэкенде:
  - `/payoff-chart` - не реализован в бэкенде
  - `/trade-log` - не реализован в бэкенде  
  - `/export` - не реализован в бэкенде
  - `/greeks/summary` - не реализован в бэкенде
  - `/iv-history` - не реализован в бэкенде

- **Решение:** Временно отключены эти endpoints с информативными сообщениями об ошибках
- **Статус:** ⚠️ Временное решение (требуется реализация в бэкенде)

### 3. **Обновление параметров по умолчанию**
- **Проблема:** Несоответствие параметров между frontend и backend
- **Решение:** Обновлены параметры по умолчанию:
  - `getPriceHistory()`: `symbol='BTC-PERPETUAL'` → `symbol='BTCUSDT'`
  - `getPriceHistory()`: `days=1825` → `days=365`
- **Статус:** ✅ Исправлено
