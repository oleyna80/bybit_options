# Skill: Portfolio Risk Budgeting

## Назначение
Системно распределять риск по активам/экспирациям/конструкциям и контролировать концентрации.

## Входные данные
- Текущий портфель: `reports/latest_analysis.md`
- Лимиты риска: из `skills/risk-management.md`

## Проверки
1. **Concentration Risk**: доля экспирации/страйка/стратегии в риске.
2. **Exposure Balance**: распределение Δ/ν/Γ по портфелю.
3. **Capital Allocation**: доля используемой маржи.

## Решения и действия
- Установить риск‑бюджеты по экспирациям и активам.
- Снизить концентрации в «узких» точках (один срок/страйк).
- Перераспределить риск между short/long premium.

## Выходной артефакт
Таблица риск‑бюджета:
```
| Bucket | Limit | Current | Action |
```

## Ограничения
- Любая новая сделка должна укладываться в риск‑бюджет.
- При превышении лимитов — приоритет разгрузки, а не добора.
