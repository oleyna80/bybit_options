# Skill: Execution & Microstructure

## Назначение
Минимизировать издержки и операционные риски при исполнении опционных стратегий.

## Входные данные
- Стакан/спреды (если доступны), параметры инструмента, размер позиции.
- Контекст ликвидности рынка (время суток, событие, экспирации).

## Проверки
1. **Bid/Ask spread**: допустимость входа/выхода.
2. **Market depth**: хватит ли ликвидности под размер.
3. **Slippage tolerance**: допустимая потеря на исполнении.

## План исполнения
- Разбить крупный объём на части (staggered orders).
- Использовать лимитные заявки при широких спредах.
- Избегать агрессивного исполнения в моменты новостей.

## Выходной артефакт
Короткий план:
```
Entry: type/price/size
Exit: type/price/size
Max slippage: X
Liquidity risks: ...
```

## Ограничения
- При расширении спредов или аномальной ликвидности → снизить размер или **PAUSE**.
