# Skill: Options Portfolio Management

## 1. Capabilities
This skill allows the agent to analyze the current portfolio state and propose specific trade adjustments using the Bybit platform context.

### A. Analyze Portfolio Health
- **Trigger:** "Analyze current positions" or "Check portfolio risk".
- **Input:** Read `reports/latest_analysis.md` (generated by your project).
- **Action:**
  1. Check Margin Utilization (Alert if > 40%).
  2. Check Net Delta per Coin (BTC, ETH).
  3. Identify "Problem Children" (Positions with high negative P&L or Gamma risk).
- **Output:** Summary of risks + Suggestions.

### B. Generate Adjustment Plan (The "Fixer")
- **Trigger:** "Propose adjustments" or "Fix the delta".
- **Action:** Create a strategic plan to re-balance the portfolio.
- **Output Format:** You MUST produce a **Markdown Table** with specific instructions.

#### Template for Adjustment Table:
| Strategy / Leg | Status | Issue (Greek) | Proposed Action | New Strike/Exp | Est. Impact |
|:---|:---|:---|:---|:---|:---|
| BTC Iron Condor | ⚠️ Threatened | High Negative Delta (-0.8) | **Roll Put Side Up** | Sell 95k Put → 98k Put | Δ becomes -0.2, Credit +$50 |
| ETH Naked Call | ✅ Stable | Theta collecting | **Hold** | N/A | Theta +$20/day |
| Hedge Futures | 🔴 Drag | Over-hedged | **Trim Short** | Buy 0.1 BTC Perp | Δ becomes Neutral |

### C. Execute Orders (Authorized Mode)
- **Trigger:** "Execute plan" or "Open trade [Details]".
- **Action:**
  1. If `dry-run` is active: Generate a JSON plan for review.
  2. If `live` is authorized: Use `Trading Module` tools (API) to place orders.
  - *Constraint:* Always check limits before placing.

## 2. Integration Notes
- **Context:** You have access to the `Bybit Options Platform` codebase.
- **Tools:** You can ask to run `python main.py` to refresh data before analysis.
