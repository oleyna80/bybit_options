# Skill: Volatility Surface & Skew

## Назначение
Системно интерпретировать структуру волатильности (term structure) и перекосы (skew) для выбора экспираций/страйков и управления риском в опционах.

## Входные данные
- Контекст волатильности: `GET /api/v1/volatility/context?symbol=BTC&include_smile=true&expiry=...`
- История IV/Skew (если доступна): `GET /api/v1/volatility/iv-rank/history?symbol=BTC&days=365`

## Ключевые метрики
- **ATM IV** и **IV Rank/Percentile**
- **Term Structure**: IV по экспирациям (кривая волы)
- **Skew**: put/call skew, slope, steepness
- **IV/HV ratio**: оценка «дорого/дёшево»

## Интерпретация
### Term Structure
- **Backwardation (короткая IV > дальняя)** → рынок боится ближайшего события/риска
- **Contango (короткая IV < дальняя)** → ожидание роста неопределённости в будущем

### Skew
- **Put skew растёт** → усиливается спрос на защиту, повышенный downside‑risk
- **Call skew растёт** → рынок переплачивает за upside‑экспозицию

## Решения и действия
1. **Выбор экспирации**
   - Событийный риск → использовать ближние экспирации, но учитывать IV crush.
   - Длинный горизонт → предпочесть средние/дальние, если IV ниже fair‑value.
2. **Выбор страйков**
   - Сильный put‑skew → дорогие путы; продавать крылья аккуратно.
   - Плоский skew → симметричные конструкции у ATM.

## Ограничения/риски
- Любой вывод должен иметь **сценарий инвалидации**.
- При высокой неопределенности или плохих данных → **PAUSE**.

