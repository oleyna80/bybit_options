# Skill: Market Structure Analysis

## Description
Понимание рыночной структуры для принятия торговых решений.

## Triggers
- "анализ рынка", "market structure", "S/R levels", "тренд"

## Key Concepts

### Price Action
- **Higher Highs/Higher Lows** → Uptrend
- **Lower Highs/Lower Lows** → Downtrend
- **Break of Structure (BOS)** → Trend confirmation
- **Change of Character (CHoCH)** → Potential reversal

### Support/Resistance
- **Horizontal Levels** — previous swing highs/lows
- **Dynamic Levels** — moving averages, trendlines
- **Volume Profile** — POC, VAH, VAL

### Market Phases
1. **Accumulation** — range after downtrend
2. **Markup** — uptrend
3. **Distribution** — range after uptrend
4. **Markdown** — downtrend

## Analysis Framework
1. **HTF Context** (D1/W1) — overall bias
2. **MTF Structure** (H4) — trend direction
3. **LTF Entry** (H1/M15) — entry timing
